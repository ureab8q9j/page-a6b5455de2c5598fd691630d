操作说明

果粒橙采用标准订阅链接。完成套餐开通后，在用户中心复制订阅 URL，再于客户端中新增订阅并更新节点。本页只提供流程说明，不收集账号信息。

  1. 对照上方套餐确定流量与设备数，年付可减少续费次数。
  2. 开通后复制订阅地址，勿在公开群转发以免被滥用导致流量异常。
  3. 按系统下载对应客户端（见下一节），仅使用官方发布渠道。
  4. 在客户端选择「订阅 / 配置 / 从 URL 导入」，粘贴并更新。
  5. 开启系统代理或 TUN 模式，按规则分流；流媒体选解锁节点，游戏选 IPLC 或游戏向标签。
  6. 若无法连接，先更新订阅、更换端口协议或切换同一区域备用节点。

分流建议

国内网站与应用直连，国际流量走代理。流媒体可指定地区节点；下载类大文件尽量错峰或使用高带宽 VIP 节点。团队版支持定制路由，可把办公域名固定到指定出口。

常见问题

果粒橙是什么？和普通 VPN 有何不同？

果粒橙是以机场订阅为核心的网络加速服务，一次订阅可在多客户端、多节点间切换。相比单一 VPN 出口，更方便按流媒体、游戏或办公切换线路，并按套餐限制流量与同时在线设备。

如何在官网完成客户端下载与导入？

先在本页「客户端下载」确认系统对应的软件名称，到该软件官方站点或应用商店安装。打开软件后选择从 URL 添加订阅，粘贴果粒橙用户中心提供的链接并更新。不要下载第三方打包的「果粒橙安装器」。

三个套餐该怎么选？年付如何计算？

轻度使用选基础版（100GB / 3 台）。高清与游戏选旗舰版（300GB / 5 台，含 IPLC 与全节点解锁）。多人共用选团队版（1000GB / 20 台）。年付分别为 ¥150、¥350、¥850，相当于约十个月的价格。

流量用尽或设备超限会怎样？

当月流量用尽后可能限速或暂停，次月重置。同时在线超过套餐台数时，新连接可能失败或挤占旧连接。可升级套餐或减少同时挂起的设备。路由器共享也计入在线数。

是否支持退款以及如何联系支持？

新用户如遇客户端不兼容或节点无法满足基本访问，可在开通初期通过工单说明环境与日志。旗舰版提供 7x24 优先工单，团队版另有客户经理通道。具体时限以开通时展示的规则为准，建议先在一至两台设备上完成测试。

节点覆盖哪些地区？游戏延迟如何理解？

常用方向包括香港、日本、新加坡、美国、台湾与韩国等。旗舰版 IPLC 针对部分游戏大区做专线优化，降低跨网绕行，但不等于固定某一毫秒数，实际体验随本地宽带与时段变化。竞技类请关闭无关下载并使用游戏标签节点。
